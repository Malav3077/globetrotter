# GlobeTrotter

Personalized multi-city travel planning application.

Plan a trip across multiple cities, build a day-wise itinerary, add activities
to each stop, and track the budget as the trip takes shape.

## Features

- Multi-city trip creation with dates and descriptions
- Itinerary builder with per-stop cities, dates and activities
- City and activity search with filters
- Automatic budget breakdown (transport, stay, activities, meals)
- Calendar and timeline views of a trip
- Shareable public itineraries
